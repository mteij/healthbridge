This is a private API server. There is nothing to see here without the Android app or an API key.

1. Install the app

Download the latest APK from GitHub releases, or add it to Obtainium to get updates automatically (repository: https://github.com/mteij/healthbridge).

Sign in with this server's address:

2. Create an API key for scripts and AI tools

Keys are read-only. Log in once, then create one:

curl -s -X POST /api/v2/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"you","password":"…"}'

curl -s -X POST /api/v2/apikeys \
  -H "Authorization: Bearer <token from login>" \
  -H 'Content-Type: application/json' -d '{"name":"my-agent"}'

The key (hb_…) is shown once. Use it as Authorization: Bearer hb_….

3. Use the data

GET  /api/v2/workouts?limit=5
POST /api/v2/fetch/steps
POST /mcp   (MCP server for AI assistants)

MCP clients: add /mcp as a remote HTTP server and send the key as a Bearer token. Tools: get_overview, list_workouts, get_workout, get_daily_totals, get_sleep, get_latest_measurements.
